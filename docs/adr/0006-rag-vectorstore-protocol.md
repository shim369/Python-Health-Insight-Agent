# 0006: RAGはVectorStoreをProtocolにしてNumPyで実装

- 状態: 採用

## 背景
振り返りメモ(数十〜数千件)を意味検索したい。専用のベクトルDBは現段階では過剰。

## 決定
- `VectorStore` Protocol(`upsert/search/count/delete_user`)。**searchは必ず `user_id` で絞る**。
  実装はNumPyのメモリ上コサイン類似度。件数が増えたら同じProtocolでpgvectorに差し替える。
- 埋め込みは `EmbeddingProvider` Protocol。Gemini実装と、キー不要の文字n-gramハッシュ実装(Fake)。
- 索引はメモの件数・最終日が変わったときだけ作り直し、埋め込みはテキストのハッシュでキャッシュする
  (コスト管理)。モデルごとに名前空間を分ける。
- 送るのはメモ本文のみ。LLMには日付つきの原文だけを渡し、「返ったメモだけを引用する」と指示する。

## 結果
- キー無しでも検索の挙動をテスト・評価できる(ただしハッシュ埋め込みは意味理解をしない)。
- 再起動すると索引はメモリから消える(埋め込みはキャッシュから復元できるので再計算は発生しない)。

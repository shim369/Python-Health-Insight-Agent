# 0007: Python 3.15.1の採用とmlflowの注意点

- 状態: 採用(CIで失敗した場合のみ3.13へ後退)

## 背景
指定は Python 3.15.1。既存アプリは3.13。依存の対応を実測した。

## 決定
- 3.15.1 で進める。FastAPI・SQLAlchemy・psycopg・google-genai・LightGBM・numpy・scipy・sqlglot・mcp は
  wheelがあり、import・動作を確認済み。
- **mlflow は依存の pyyaml に3.15用のwheelが無く、ソースからビルドされる**(導入・import は成功)。
  wheelのみの環境では解決に失敗する。CI(ubuntu)ではビルドできる見込みだが、push後に確認する。
- google-genaiはimport時に `SyntaxWarning` を出す(無害)。pytestで警告をエラー化する設定は使わない。
- google-genai 3.xは `httpx` ではなく `httpx2` を使う。タイムアウト判定は特定ライブラリに依存せず、
  例外クラス名で行う。

## 結果
- 3.15で動く一方、新しいPythonの依存環境は変動しやすい。CIが失敗したら3.13(全依存がwheel)へ戻す。

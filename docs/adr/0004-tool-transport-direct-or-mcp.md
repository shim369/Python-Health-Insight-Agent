# 0004: ツールの呼び方を直接/MCPで切り替える

- 状態: 採用

## 背景
ツール群は他のエージェント/クライアントからも使えるとよい(MCP)。一方、同一プロセス内の直接呼び出しは
速くて単純で、デバッグしやすい。

## 決定
- エージェントループは `ToolExecutor` Protocol にだけ依存する。実装は `ToolRegistry`(直接)と
  `McpToolExecutor`(MCP経由)。`TOOL_TRANSPORT=direct|mcp` で切り替える。
- MCPサーバーは低レベルAPIで、**直接呼び出しと同じツール定義・同じ結果**を公開する。LLM向けの内容は
  `content`、件数とグラフは `structured_content` に分けて運ぶ(グラフはLLMへ渡さない)。
- ユーザーはサーバー起動時に束縛する(ADR 0002)。
- 同期のエージェントから非同期のMCP SDKを呼ぶため、専用スレッドのイベントループにセッションを保持する。

## 結果
- 「直接」と「MCP」(インメモリ・stdio子プロセス)で結果が同一であることをテストで固定している。
- MCP経由はプロセス起動と往復のぶん遅い(CLIでの実測は初回約1秒)。デモ・統合の柔軟性とのトレードオフ。
